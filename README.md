## 明细

### 01-爬虫脚本

- `票务/` — 12306 抢票、代售点信息、大麦网抢票
- `数据采集/` — B站、喜马拉雅、淘宝京东、虎牙、百度文库、知网、软科排名、股票基金、小说、地理位置等

### 02-小游戏

- `五子棋/`、`俄罗斯方块/`（含 step1-step10 分步源码与 pptx）、`贪吃蛇/`（150 行版 / 200 行版）

- `个人网站/` — Django 项目，含 DjangoUeditor 富文本编辑器
- `HuaXunLogin/` — 登录页（HTML/CSS/JS）

### 04-数据与可视化

- `GDP地图/` — 分省年度数据 + 地图绘制脚本
- `知网data.xlsx`、`肯德基.csv`

### 05-学习资料

- `电子书/` — Python Cookbook、Python编程快速上手、利用Python进行数据分析、Python背记手册、嵌入式深度学习
- `音乐素材/` — mp3 文件

- AI聊天机器人、文本摘要、微信消息、VIP视频相关脚本
