# event-planning-kit

活动策划天团共用的模板与规范包。把「策划书八段式」「预算表」「风险预案」「宣传文案」四种结构固化下来，确保每个团员产出格式统一、可直接拼装成最终 HTML 策划方案。

## 何时使用
- 主理人启动任意活动策划任务时预加载，作为全团统一的结构基线。
- 任一团员在撰写自己负责段落时，引用对应模板的字段与表格样式。

## 包含模板
- `references/策划书八段式模板.md` — 策划书总框架（主题→背景→时间→人员→流程→准备→预算→注意事项），红字标注的颗粒度要求必须落实。
- `references/预算表模板.md` — 支出项目 / 数量 / 单价 / 总价 / 合计，含 10% 备用金。
- `references/风险预案模板.md` — 风险项 / 类型 / 等级 / 预防 / 处置 / 责任人 / 备用方案。
- `references/宣传文案模板.md` — 推送 / 海报 / 招募三段式结构。

## 使用约定
1. 八段式顺序不可乱：一主题、二背景意义、三时间、四参与人员、五内容与流程、六活动准备、七预算、八注意事项。
2. 第四至第七段的红字要求（分工到人、联系方式、单价合计、发言到人）是硬性颗粒度，缺失视为不合格。
3. 预算与筹备金额必须互相印证；风险预案必须覆盖流程关键节点。
