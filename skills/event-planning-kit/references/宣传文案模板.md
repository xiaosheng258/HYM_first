# 宣传文案模板

## 推送文案（微信群 / 公众号）
- 标题：<一句话钩子，避免"欢迎参加"式废话>
- 正文三段式：
  - 钩子：<为什么要来，痛点或爽点>
  - 信息：时间 <>，地点 <>，对象 <>
  - 行动：扫码报名，截止 <>
- 语气：<活泼 / 正式，按人群切换>

## 海报文案
- 主标题：<Slogan，有记忆点>
- 副标题：<一句话补充>
- 信息块：时间 / 地点 / 报名二维码占位
- 情绪与配色建议：<如 活力橙、年轻感>

## 招募话术（口播 / 私聊）
<30 秒能说完的一版，含钩子+时间地点+报名>

规则：
- 时间 / 地点 / 报名方式必须与策划书方案一致，不得夸大承诺。
- 针对大一新生、社团骨干、校外嘉宾等人群切换语气与钩子。
- 导出宣传 PPTX（3-5 页：封面 slogan+时间地点、亮点页、报名页），命名 `宣传_<活动名>.pptx`。
