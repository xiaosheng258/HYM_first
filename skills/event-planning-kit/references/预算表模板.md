# 活动预算表模板

字段：支出项目 / 数量 / 单价(元) / 总价(元) / 说明

示例：

| 支出项目 | 数量 | 单价(元) | 总价(元) | 说明 |
|----------|------|----------|----------|------|
| 场地费 | 1 场 | 0 | 0 | 校内免费 / 或外租 |
| 物料-签到表/笔 | 80 份 | 2 | 160 | 含 10%-15% 备用 |
| 餐饮-矿泉水 | 100 瓶 | 1.5 | 150 | 含备用 |
| 奖品 | 10 份 | 30 | 300 | 互动抽奖 |
| 宣传物料 | 1 批 | 200 | 200 | 海报/横幅 |
| 机动备用金 | — | 合计×10% | <X> | 不可预见支出 |
| **合计** | | | **<总额>** | |

规则：
- 数量与筹备清单一致；单价需有依据（市场价/报价）。
- 合计叠加 10% 机动备用金，给出总预算上限。
- 标注可压缩项与不可省项，给出≥3 条省钱建议。
- 导出 Excel，命名 `预算表_<活动名>.xlsx`，末行用公式合计。
